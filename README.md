# Housecall Pro assistant for Claude and ChatGPT

Ask about your customers, jobs, estimates, invoices and schedule in plain English, from the Claude desktop app
(Mac or Windows) or the Codex tab of the ChatGPT desktop app (Mac). **Works on any Housecall Pro plan, including
Basic and Essentials.**

## Why it works without MAX

Housecall Pro's API is available on the MAX plan only, and only an Admin can create a key. Connectors and MCP
servers built on that API need MAX. This assistant does not use the API: it works the normal Housecall Pro screens
in a browser window you sign in to yourself, so the plan does not matter and there is no key to create or share.

## What you can ask

- "Which estimates did we send last month that were never approved?"
- "Which invoices are still unpaid from more than 30 days ago?"
- "What is on Tuesday's schedule, and who is assigned to each job?"
- "Find the job on Elm Street and add a note that the part is on order."

It asks for your yes before it creates or changes anything in your account, such as a customer, job, estimate
or note. If you would rather it make drafts like those without asking, tell it. Anything that reaches a customer,
moves money, deletes something or changes settings always waits for your yes.

## Requirements

- Claude: a Mac or Windows computer, the Claude desktop app on a paid Claude plan, and your own Housecall Pro login.
- ChatGPT: a Mac, the ChatGPT desktop app on Plus, Pro, Business, Enterprise or Edu (Codex tab), and your own Housecall Pro login.
- Normal ChatGPT chat and the phone apps are not supported.
